## Starting an Event Has a Page Now

Creating an event used to happen in a dialog — a box over the top of whatever
you were already looking at. On a phone it did not fit. The form ran off the
bottom of the screen, the button that actually creates the thing sat below the
edge, and the two date fields, squeezed side by side, had both shrunk to
"Pick a dat…".

![Creating an event, with the form laid out down the page](./images/create-event.png)

It is a page now, with room to breathe: what the event is called, when it runs,
and who can see it. Each of those is its own block instead of one long stack of
fields, and nothing hides behind a scrollbar inside a box.

## Less to Read Through

The default time window — the hours the availability grid opens on — was the
largest part of the old dialog and the part almost nobody fills in. It is folded
away now, under a line that says what it is currently set to. Open it if you
want it. Ignore it and it reads "availability covers the whole day", which is
exactly what happens.

## On a Phone

![Creating an event on a phone](./images/create-event-mobile.png)

The two date fields sit one above the other, so each shows a whole date rather
than an ellipsis, and Create is where every button on a phone should be: at the
end of the form, across the full width.

## Accounts for People Only

Anyone can sign up for WirkSam — that is deliberate. But an open form is also an
open invitation to a script, and nothing stopped one from making accounts all
afternoon, sending a verification mail to a different stranger each time.

Registration now sits behind a Cloudflare Turnstile check: the box that usually
ticks itself while you are still reading the rest of the form. If it cannot tell
that you are a person, no account is created and no mail goes out.

This is something each WirkSam installation switches on. Until whoever runs the
server sets it up, the check is off — so a copy of WirkSam running on somebody's
laptop does not need it.

## Smaller Touches

- A start date after the end date is no longer possible: the two fields limit
  each other, and the page tells you how long the event comes out.
- An event you create is live immediately. Creating one from the management list
  used to leave it a draft that nobody else could see.
- Creating an event from the event picker brings you back to the picker with the
  new event already selected, ready to carry on with.
- In German the button said "Veranstaltungsgruppe erstellen", a word the rest of
  WirkSam dropped a while ago. It now says "Veranstaltung erstellen".
